SUSE Product Builder
====================

This tooling was used up to openSUSE Leap 15.x and SLES 15 to build
installation images and rpm repositories.

It is only maintained for these former code streams with absolute minimal
changes. 

For current openSUSE Leap 16.x or SLFO based products please look for
product-composer instead:

  https://github.com/openSUSE/product-composer
